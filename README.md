**Live website:/** ** https://lol-lab48.github.io/VameroWebStudio

## Features

- Responsive layout for desktop and mobile
- Overview of services and selected website concepts
- Contact section with email and phone links
- Enquiry form connected through FormSubmit

## Run locally

1. Download or clone this repository.
2. Keep the main website file named `index.html`.
3. Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Upload `index.html` and this `README.md` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select your main branch and the `/ (root)` folder, then save.
4. Once GitHub Pages publishes the site, replace the placeholder link at the top of this README with your actual website URL.

## Enquiry form setup

The contact form is configured to send submissions to `gabe.karekinian@gmail.com` using FormSubmit. FormSubmit may send a one-time activation email to that address before the form can deliver enquiries. Complete that activation when it arrives.
