# Northline Studio website

A responsive, single-page website for a web design and development agency.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will provide your live website URL.

## Before publishing
- Change the brand name, copy, services and portfolio concepts to match your real business.
- In `index.html`, replace `hello@yourcompany.com` with your real enquiry email.
- The portfolio tiles are illustrative concepts, not real client work.
- The contact form uses the visitor's email app (`mailto:`); it does not store submissions. For a hosted form, connect a form service or backend.
- Google Fonts are loaded online; the page still has fallback fonts if they are unavailable.
